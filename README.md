# Create: Avionics

**Create: Avionics** is an addon for Create Aeronautics that adds compact components for ultralight and small aircraft.

## ✈️ Features
* **Ailerons**: Adjustable max angle, wear system (looseness), and jamming risk during sharp maneuvers. Can be repaired with a wrench.
* **Small Engine**: Compact power source (up to 4096 SU). Requires water for cooling and fuel (coal/wood).
* **Lava Engine**: A two-block monster generating 8192 SU. Runs on lava and requires a lot of water. Explodes if overheated!

## 📥 Installation
1. Install Minecraft 1.21.1 and NeoForge.
2. Install required dependencies: **Create**, **Sable**, **Create Aeronautics**.
3. Download the `.jar` file from the [Releases](../../releases) page and put it in your `mods` folder.

## 🛠️ Building from Source
To compile the mod, you will need the dependency `.jar` files (Create, Sable, Ponder, etc.). Place them in the `libs/` folder and run:
```bash
./gradlew build
```

# Create: Avionics

**Create: Avionics** — это дополнение для Create Aeronautics, добавляющее компактные компоненты для ультралайтов и небольших самолетов.

## ✈️ Возможности
* **Элероны**: Настраиваемый максимальный угол, система износа (люфт), риск заклинивания при резких движениях. Требуют ремонта гаечным ключом.
* **Малый двигатель**: Компактный источник вращения (до 4096 SU). Требует воду для охлаждения и топливо (уголь).
* **Лава-Двигатель**: Двухблочный монстр на 8192 SU. Работает на лаве, требует много воды. При перегреве — взрывается!

## 📥 Установка
1. Установите Minecraft 1.21.1 и NeoForge.
2. Установите обязательные зависимости: **Create**, **Sable**, **Create Aeronautics**.
3. Скачайте `.jar` файл из раздела [Releases](../../releases) и положите его в папку `mods`.

## 🛠️ Сборка из исходников
Для компиляции мода вам понадобятся `.jar` файлы зависимостей (Create, Sable, Ponder и др.). Поместите их в папку `libs/` и запустите:
```bash
./gradlew build
```
